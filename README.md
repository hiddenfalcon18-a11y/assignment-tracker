# AI Employee Training & Assessment Portal

A comprehensive, AI-driven employee training and performance management platform built entirely in Python. This system automates assessment generation, grading, and analytics while providing admins with powerful group and course management capabilities.

## 🎯 Key Features

### Admin Dashboard
- **Group Management**: Create, manage, and organize employee groups
- **Course Assignment**: Assign language-specific courses (C++, C, ISTQB, Python, etc.) to groups
- **PPT Upload**: Upload training materials (PDFs/PPTs) - only manual upload by admin
- **Performance Tracking**: Monitor employee progress and assessments

### AI-Powered Features (Automated)
- ✅ Automatic question generation from uploaded training materials
- ✅ Intelligent assessment creation and distribution
- ✅ Real-time answer evaluation and scoring
- ✅ Personalized learning recommendations
- ✅ Performance analytics and insights
- ✅ Adaptive difficulty levels based on performance

### Employee Portal
- 📚 Personalized learning dashboard
- 🎯 Access to assigned courses
- 📝 Complete assessments (weekly, monthly, yearly)
- 📊 View performance history and certifications
- 💡 Get AI-powered recommendations

### Assessment Management
- Weekly assessments (auto-generated by AI)
- Monthly assessments (manual + AI hybrid)
- Yearly assessments (comprehensive evaluation)
- Record keeping and history tracking

## 🏗️ Tech Stack

- **Backend**: FastAPI (Python)
- **Database**: PostgreSQL/SQLAlchemy
- **AI/ML**: OpenAI API, LangChain, Hugging Face
- **PDF/PPT Processing**: PyPDF2, python-pptx
- **Frontend**: Streamlit (for rapid deployment) or Flask
- **Task Queue**: Celery + Redis (for background AI processing)
- **Authentication**: JWT tokens
- **API Documentation**: Swagger/OpenAPI

## 🚀 Quick Start

### Prerequisites
- Python 3.10+
- PostgreSQL 12+
- Redis (for background tasks)
- OpenAI API key

### Installation

```bash
# Clone the repository
git clone https://github.com/hiddenfalcon18-a11y/assignment-tracker.git
cd assignment-tracker

# Create virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r backend/requirements.txt

# Set up environment variables
cp backend/.env.example backend/.env
# Edit .env and add your OpenAI API key and database credentials

# Initialize database
python scripts/init_db.py

# Run the backend
cd backend
uvicorn app.main:app --reload

# In another terminal, run the frontend
streamlit run frontend/streamlit_app.py
```

### Docker Deployment

```bash
docker-compose up --build
```

## 📊 System Architecture

### Data Flow
1. **Admin Upload**: Admin uploads PPT/PDF → System extracts content
2. **AI Processing**: LLM generates questions → Creates assessments
3. **Employee Assessment**: Employee takes test → AI grades answers
4. **Analytics**: System generates insights → Admin dashboard shows metrics

### User Roles
- **Admin**: Full access, group management, course assignment, PPT uploads
- **Manager**: View team performance, approve assessments
- **Employee**: Take assessments, view progress, access courses
- **AI Agent**: Background processing, question generation, grading

## 🤖 AI Workflows

### Assessment Generation Flow
```
PPT Upload → Content Extraction → AI Question Generation → 
Question Validation → Assessment Creation → Distribution
```

### Grading Flow
```
Answer Submission → AI Analysis → Scoring → 
Feedback Generation → Record Saving → Analytics Update
```

### Recommendation Flow
```
Performance Analysis → Skill Gap Identification → 
Learning Path Recommendation → Adaptive Content Selection
```
